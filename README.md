# Zelestia
## Dev Enviroment
1. Run `docker-compose up -d` in the terminal to start the postgres database.
2. Run `mix setup` in the terminal.
3. Start the server with `mix phx.server` or inside IEx with `iex -S mix phx.server`

Now you can visit [`localhost:4000`](http://localhost:4000) from your browser.
